# 傳統影像檢測基線

測試日期：2026-08-16  
資料集：Kolektor Surface-Defect Dataset 2 官方 test split  
測試影像：1,004 張（110 張瑕疵、894 張正常）

## 方法

1. 將輸入轉成 8-bit 灰階影像。
2. 使用積分影像計算每個像素的局部背景平均。
3. 以像素與局部背景的差異產生候選瑕疵遮罩。
4. 使用八方向連通元件移除小面積雜訊。
5. 依瑕疵像素比例進行 OK／NG 判定。

固定參數：局部半徑 8、差異門檻 28、最小瑕疵面積 10 px、拒收面積比例 0.05%。

## 結果

| 指標 | 結果 |
|---|---:|
| True Positive | 64 |
| True Negative | 858 |
| False Positive | 36 |
| False Negative | 46 |
| Accuracy | 91.83% |
| Precision | 64.00% |
| Recall | 58.18% |
| Specificity | 95.97% |
| 平均核心處理時間 | 0.90 ms／張 |

## 判讀

這個基線速度快，且能正確排除大部分正常品，但瑕疵召回率只有 58.18%，代表仍會漏掉較小或對比不足的缺陷。因此它適合作為可解釋的傳統影像處理基準，不應單獨宣稱為可上線的完整檢測模型。

下一階段會加入 AI 推論，目標是提高瑕疵召回率，同時控制誤判與推論時間；傳統基線會保留作為備援與交叉判定訊號。
